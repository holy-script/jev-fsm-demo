# 06. Asset pipeline

All art, audio and music is third-party and **gitignored** (`assets/`, `public/game-assets/`, `public/duel-assets/`). A fresh clone has none of it. Tiled maps are generated by scripts and **are** committed (`public/maps/`), but they reference tiles that must be built. This document explains what is used, where it comes from, and how the build scripts turn raw packs into what the games load.

`tools/README.md` has the licence table and the short command list; this is the deeper reference.

## Directory conventions

```
assets/_dl, _dl2, _dl3     raw downloaded zips/rars (per-pack folders)
assets/packs               unzipped v2 packs  (folder name = "<slug>__<zip-name>")
assets/packs2              unzipped v3 packs  (folder name = slug)
assets/packs3              unzipped v3 audio/VFX packs
public/game-assets         OUTPUT of prep_assets.py (v2)
public/duel-assets         OUTPUT of prep_duel_assets.py (v3)
public/maps                Tiled JSON (generated, committed)
```
Several additional packs were downloaded while evaluating options (soulslike characters, king/warrior packs, swamp bosses, dungeon tileset, music packs, etc.). They are not used by any current build step; ignore them or delete them.

## Step 1: download

`tools/itch_download.mjs [boss-rush|duel]` drives Chromium through each itch.io page: open `<page>/purchase`, click "No thanks, just take me to the downloads" (`.direct_download_btn`), then click every `.download_btn` whose upload name looks like an archive and save it. Output goes to `assets/_dl/<slug>/` (boss-rush set) or `assets/_dl2/<slug>/` (duel set). Notes:
- itch pages sit behind Cloudflare and have been intermittently unavailable (522). Retrying later worked.
- The `duel` set only lists the three packs it needs (Szadi, Ninja Adventure, Darkpixel). The VFX packs (v-ktor "Pixelated Attack/Hit Animations", Pimen "Smoke VFX 1" and "Cutting and Healing") and StarNinjas sounds went into `assets/packs3`: the sword sounds by `tools/fetch_sfx.sh` (curl from OpenGameArt then unzip), the VFX packs by the same Playwright flow into `assets/_dl3/<slug>` then unzipped. If you rebuild from scratch, add their itch URLs to a new set in `itch_download.mjs` (slugs the prep script expects: `pixelated-attackhit-animations`, `smoke-vfx-1`, `cutting-and-healing`).
- `.rar` archives (Golem pack) need `bsdtar` (macOS has it) for extraction.

Unzip commands (also in `tools/README.md`):

```bash
# v2
cd assets && mkdir -p packs && for z in _dl/*/*.zip; do n=$(basename "$(dirname "$z")")__$(basename "$z" .zip | tr ' ' '_'); mkdir -p "packs/$n" && unzip -q -o "$z" -d "packs/$n"; done; cd ..
# v3
cd assets && mkdir -p packs2 && for f in _dl2/*/*.zip _dl2/*/*.rar; do n=$(basename "$(dirname "$f")"); mkdir -p "packs2/$n" && bsdtar -x -f "$f" -C "packs2/$n"; done; cd ..
sh tools/fetch_sfx.sh      # 20 CC0 sword sounds into assets/packs3
```

## Step 2a: v2 art (`npm run assets` = `prep_assets.py` + `make_maps.py`)

- Slices each character's per-animation PNG frames (or strips) into one horizontal strip per animation, writes `public/game-assets/<sheet>/<Anim>.png`, and records in `manifest.json` per sheet: file, frame size, frame count, **measured bounding box** of the real pixels and a derived body box (used for hurtboxes and foot anchors).
- Re-cuts the source tileset (it sits on a 1 px offset grid) onto a clean 16 px grid and exports parallax background layers.
- `make_maps.py` writes `public/maps/arena_1..3.json` with tile layers `ground`, `platforms` and an object layer `spawns` (`player`, `boss`).

## Step 2b: v3 art (`npm run assets:duel` = `prep_duel_assets.py` + `make_duel_map.py`)

`prep_duel_assets.py` deletes and recreates `public/duel-assets/` every run, so it is deterministic. It writes `manifest.json` with `sheets`, `tiles`, `audio`, `music`.

| Section | What it does |
|---|---|
| `strip(key, glob, dest)` | Concatenates per-frame PNGs into one strip PNG; records frame size, count, `bbox` (union of non-transparent pixels) and `first` (first-frame bbox). `Fighter` derives foot anchors from `first` of the idle sheet: `ax = (first.left + first.right)/2 - 3`, `ay = first.bottom`. |
| Hero (Szadi "Player") | keys `hero_idle walk run atkA..D kick blockUp block blockHigh roll hitA hitB dead` |
| Shield Skeleton (enemy 2) | keys `cap_idle walk atkA atkB hit dead block jump` (the Captain) |
| Grunts (enemies 1 and 4) | prefixes `sk` (sword) and `sp` (spear): `idle walk atkA atkB hit dead` |
| Golem | one 10x10 grid of 100x100 cells; `grid_strip(key, cells, dest)` slices a row (or chosen cells) per animation: `golem_idle glow arm block hit melee laser armor dead`. Also builds `fx_beam` (laser frames 9-14 of `Laser_sheet.png`, 300x100 each, origin 40,33) and `fx_fist` (3x2 grid of the projectile) |
| Bringer of Death | `bod_idle walk atkA cast hit dead` from the Individual Sprite frames (140x93 each), `bod_block` (the first five Cast frames, a hunched pose, reused as a guard) and `fx_spell` (16 frames of the Spell effect, a portal and column). Art **faces left** (`nativeDir -1` in `data.ts`) and the scythe skews the bbox, so `anchorX: 106` (measured torso centre) is set in the BossDef |
| VFX | `vfx_strip(key, pack, file, fw, fh, cols, n)` crops frames from sprite sheets into strips (all white-on-transparent except the heal sparkle, so they tint at runtime): `vfx_hit01 hit03 hit05 impact01 break01 blood shards splash smoke heal` |
| Tileset | Repacks Ninja Adventure `TilesetRelief.png`: a 4x3 plateau and a 3x3 tall cliff into a 7x3 strip, 16 px tiles |
| Audio | 20 CC0 sword clashes/swings -> `clash1..10`, `blade1..10`, converted by ffmpeg to mono 44.1 kHz 16-bit wav with `loudnorm=I=-19:TP=-3:LRA=7` so they sit at one loudness |
| Music | Five Ninja Adventure tracks copied as ogg and analysed with `tools/bpm.py`; the result `{bpm, phase, conf, seconds}` goes into `manifest.music[key]` |

Music assignment (key: track, BPM measured): `temple` "12 - Temple" 90 (tutorial/Monastery), `castle` "10 - Dark Castle" 65 (quiet exploring, Foundry ambience), `captain` "17 - Fight" 90 (boss 1), `crypt` "40 - Crypt" 80 (Golem), `final` "24 - Final Area" 70 (Bringer).

### Prerequisites to run it
Python 3 with Pillow and numpy (`pip install pillow numpy`), `ffmpeg` on PATH, and the unzipped packs in the expected folder names. Missing inputs abort with an explicit message (for example "missing sword samples in assets/packs3").

## `tools/bpm.py` (beat detector)

Estimates **tempo and beat phase** of a track so combat can be phase-locked to it. It decodes with ffmpeg to mono 22.05 kHz, builds a spectral-flux onset envelope (low band, roughly 20 Hz to 2.5 kHz), then scans every candidate tempo from 60 to 180 BPM in 0.05 steps and every phase in 8 ms steps, scoring the summed onset strength at the predicted beats across the **whole** track. It returns `bpm`, `phase` (seconds from file start to the first beat), `conf` (winner versus median candidate; above about 2 means a clear pulse) and the duration. All five tracks measured confidently (conf 12 to 18). Fitting against the whole track (rather than a short excerpt) is what keeps the grid stable for the entire song, which matters because combat is scheduled against it for minutes at a time. Run `python3 tools/bpm.py file.ogg ...` to inspect a track.

## `tools/make_duel_map.py` (the maps)

A generator, not an editor: `build(name, dais, dividers, pillars, spawns, gate, arena, lights, shrines, lore)` stamps a nine-slice plateau (`plateau`) and cliff blocks (`cliff`) into two layers and an object layer, then writes JSON that Tiled can open for hand edits (if you hand-edit, stop re-running the generator for that map). Tile gids: the repacked tileset is 7 columns x 3 rows (`gid(col,row) = row*7+col+1`): plateau columns 1-3 (column 0 is a narrow piece you must not use for the nine-slice), cliff columns 4-6.

- **Monastery** (80x60): dais (4,3,72,54), a divider forming the Hall (north) and courtyard (south) joined by the gate gap, eight pillar blocks, spawns player (40,51), shade (40,43), npc (33,49), boss (40,14), gate (40,32), arena (12,6,56,23), a shrine (47,51), three lore slabs, braziers as `light` objects.
- **Foundry** and **Summit**: the same builder with their own layouts, lights, a shrine and lore. The Summit has `stars` enabled in `AREAS`.

Coordinates in `pt(...)` are in tiles and are converted to pixels (centre of tile).

## Adding or replacing art: checklist

1. Put the unzipped pack under the right `assets/packsN/` folder name.
2. Add `strip(...)`/`grid_strip(...)` calls in `prep_duel_assets.py` with a **new prefix** for the character (`<prefix>_<suffix>` keys).
3. If the sprite's weapon or pose skews its bounding box, measure the torso centre (for example, the mean x of opaque pixels in rows covering the torso of the idle frame) and set `anchorX` on the `BossDef`.
4. If the art faces left, set `nativeDir: -1`.
5. Add per-animation fps and looping entries in `DuelScene.ts` (`FPS` map and `LOOP` set; unspecified fps defaults to 14, non-looping).
6. Re-run `npm run assets:duel`, restart or hard-refresh the page (the manifest is cached by the browser).
7. Add credits in `MenuScene.ts` and `tools/README.md`.
8. Never commit anything under `assets/` or `public/*-assets/`.
